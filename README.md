# alluv

alluv is specialised hosting for open-weight large language models, operated by [4rce.com Digital Technologies GmbH](https://4rce.com). The site describes an OpenRouter catalogue and three inquiry paths: flat-rate lanes, dedicated GPUs, and on-premises projects. None of those paths is on sale yet.

This repository contains the public website: static HTML and CSS, served by GitHub Pages. The site uses no trackers and loads no external fonts.
