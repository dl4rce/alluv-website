# alluv

alluv is specialist LLM hosting operated by [4rce.com Digital Technologies GmbH](https://4rce.com). The public website describes purpose-built specialist model profiles and four business hosting paths: marketplace catalog access, flat-rate lanes, dedicated GPUs and on-premises projects.

This repository contains the dependency-free static website served by GitHub Pages. It loads no external fonts, scripts, analytics or trackers.

- Website: <https://alluv.ai>
- Model catalog: <https://alluv.ai/models/>
- Imprint: <https://alluv.ai/imprint.html>
- Terms: <https://alluv.ai/terms.html>
- Privacy Policy: <https://alluv.ai/privacy.html>

The website is deliberately `noindex` while alluv is pre-launch. Public material must not publish unverified performance, capacity, pricing or internal infrastructure information.
